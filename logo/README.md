# NewsPrism Logo

Das Prisma bricht einen weißen Lichtstrahl in das blau-grau-rote Spektrum
der politischen Bias-Achse (links #1e3a8a -> Mitte #6b7280 -> rechts #7f1d1d) -
die visuelle Metapher der App: eine Story in ihre Perspektiven aufgefächert.

## Dateien
- `newsprism-wordmark.svg`      Wortmarke fuer hellen Hintergrund
- `newsprism-wordmark-dark.svg` Wortmarke fuer dunklen Hintergrund
- `newsprism-icon.svg`          Quadratisches Icon (128x128, gerundet)
- `favicon.svg`                 = Icon, fuers <link rel="icon">

## Hinweis
Das Dashboard selbst rendert die Wortmarke INLINE (in newsprism.py), damit
sie per CSS dem Dark Mode folgt. Diese Dateien hier sind die eigenstaendigen
Assets zur Wiederverwendung (Favicon, externe Seiten, Praesentationen).

## Farben
- Korpus / Schrift hell:  #1f2a44   (dark: #e5e7eb / #f1f3f7)
- Akzent "Prism":         #3b82f6   (dark: #60a5fa)
- Spektrum: #1e3a8a #3b82f6 #6b7280 #dc2626 #7f1d1d  (Bias-Skala -2..+2)
